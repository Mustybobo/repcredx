RepCredX
RepCredX (Reputation & Credit Exchange) is a decentralized reputation token system built with Clarity on the Stacks blockchain.
It allows communities, DAOs, and protocols to issue, track, and exchange reputation credits as proof of trustworthiness, participation, or lending history.

Features
Reputation credits issued by admin/DAO
Transferable reputation credits
Redeemable for governance or privileges
On-chain logs for transparency
Designed for DeFi and governance integrations
